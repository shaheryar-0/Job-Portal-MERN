# MERN Job Portal

A full-stack Job Portal application built using the MERN Stack (MongoDB, Express.js, React.js, and Node.js).

## Features

### User Features

* User Registration
* User Login
* JWT Authentication
* Browse Available Jobs
* Apply for Jobs
* View Applied Jobs

### Admin Features

* Create New Jobs
* Edit Existing Jobs
* Delete Jobs
* Manage Job Listings

## Technologies Used

### Frontend

* React.js
* JavaScript
* Tailwind CSS
* Axios
* React Router DOM

### Backend

* Node.js
* Express.js
* MongoDB Atlas
* Mongoose
* JWT Authentication
* bcrypt.js

## Installation

### Clone Repository

git clone https://github.com/shaheryar-0/Job-Portal-MERN.git

### Frontend

cd frontend

npm install

npm run dev

### Backend

cd backend

npm install

npm run dev

## Environment Variables

Create a .env file in backend folder:

PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
